    Core TCL command categories

    Every command in the lab falls into one of ten categories. The category tells you what a command does to the design database: load it, configure it, change the layout, measure it, or write it out.

    How the categories fit together

    A place-and-route session moves through five roles. Only the third one changes what you see in the layout view.

      Roles 3 and 4 form a loop: a report or check points at a problem, a construction command or an engine fixes it, and you measure again. Shell commands work at any point. Legacy Innovus names are camelCase (floorPlan, addRing, placeDesign). The newer Innovus Stylus interface, ICC2 and OpenROAD use snake_case verb_object names (create_floorplan, initialize_floorplan). The lab accepts the aliases listed under each command.
