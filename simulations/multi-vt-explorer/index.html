Model and assumptions

Each flavor is the same NMOS with a different threshold set by work function (FinFET, FD-SOI) or channel doping (planar). Parameters are representative values chosen to reproduce published trends for each technology class. They are not foundry PDK data. PMOS is assumed to track NMOS.

Vth = Vth0(flavor) + ΔVcorner + κ·(T − 25 °C) − η·VDS − kb·VBS + ΔVroll-off(ΔL) ID = K(T)·[α·n·vT·ln(1 + e(VGS − Vth)/(α·n·vT))]α·(1 − e−VDS/vT) vT = kT/q K(T) ∝ (T/298 K)−θ·(Lg/L)0.4 alpha-power law above threshold, exponential below Ioff = Isub(VGS = 0) + Igate ∝ VDD4 + Ijunction/GIDL ∝ e(VDD − VBS)/Vj·e−Ea/kT SS = n·vT·ln 10 tFO4 ∝ C·VDD / Ieff, Ieff = ½·[ID(VDD) + ID(VDD/2)] at VDS = VDD

Vth,sat in the table is extracted from the curve at ID = 100 nA × W/L, the usual constant-current definition. The FO4 delay is scaled so SVT at TT, 25 °C and nominal VDD matches a typical value for the node. The zero-temperature-coefficient (ZTC) supply is where FO4 delay at −40 °C equals delay at 125 °C; below it, cold is the slow corner (temperature inversion). In FD-SOI the back gate sits under the buried oxide, so back bias does not stress any junction.
