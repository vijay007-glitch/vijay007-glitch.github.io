PnR Command Lab

Type Innovus-style TCL commands and watch a gate-level Verilog netlist become a placed, clocked and routed layout.

September 30, 2026, interactive simulator

Place and route is where a gate-level netlist becomes geometry. The tool reads the technology, the cell libraries and the Verilog, then builds a floorplan, a power grid, a legal placement, a clock tree and routed wires, one TCL command at a time. Each command changes the design database, and the next one depends on what the last one left behind.

This lab lets you type those commands and watch each one change the layout. It opens on an empty floorplan. Every physical-design command, from floorPlan and addRing to placeDesign, ccopt_design and routeDesign, updates the layout view, and a panel explains what the tool did and suggests the next step.

Open the simulator full screen. On a phone, that works better than the embedded view below.

How to use it

  • Press Run full flow to watch every step, from reading the LEF files to writing GDS. Type reset to go back to the empty floorplan.
  • Or type the commands yourself. Tab completes a command, the arrow keys step through history, and the panel under the layout always suggests what to run next.
  • The command reference lists all 64 commands, each with a Run button. Common ICC2 and OpenROAD names work as aliases.
  • Below the lab, Core TCL command categories sorts every command into one of ten categories, maps them against the flow stages, and lists what each one changes, what it needs first and what it clears when re-run.

The flow

Run full flow issues these commands in order, across the seven stages in the lab’s progress bar.

  • Import. read_lef, read_lib, read_verilog, read_sdc, init_design
  • Floorplan. floorPlan, assignIoPins, planDesign, setInstancePlacementStatus, addHaloToBlock, addEndCap, addWellTap
  • Power. globalNetConnect, addRing, addStripe, sroute
  • Place. setPlaceMode, placeDesign, timeDesign -preCTS, optDesign -preCTS
  • CTS. create_ccopt_clock_tree_spec, set_ccopt_property, ccopt_design, optDesign -postCTS
  • Route. setNanoRouteMode, routeDesign, ecoRoute -fix_drc, optDesign -postRoute
  • Signoff. addFiller, verify_drc, verifyConnectivity, streamOut

The metrics bar under the layout tracks core utilization, placed cells, wirelength, setup WNS and TNS, clock skew and DRC count as the design moves through the stages.

How this model is simplified

The design is a small SoC, mini_soc.v, on a generic 45 nm library with nine metal layers, M1 to M9. Commands follow Cadence Innovus naming. The netlist, library, timing and congestion numbers are a deliberately simplified teaching model computed from the layout, not signoff results. Use it to learn what each command does and why the order matters, not to predict real results.
